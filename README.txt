Решение задачи 3

split_secret(p, secret, n, t) создаёт список пар (номер участника, доля).
restore_secret(p, shares) восстанавливает секрет из таких пар.

p - простое число; secret - секрет; n - число участников; t - порог.
Входные данные предполагаются корректными: 0 <= secret < p,
1 <= t <= n < p. Для восстановления берут не меньше t долей
с разными номерами участников из одного разделения.
